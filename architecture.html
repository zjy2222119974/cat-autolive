架构设计说明：

  • Python 蓝色区域 (L1-L3)： 运行在电脑上的上位机程序。负责逻辑处理、网络请求和模拟器控制。这是你的核心开发工作。
  • C++ ESP32 视频小车： 由于需要处理高帧率视频流，建议使用 Arduino C++ 框架编写，保证推流流畅。
  • MicroPython 简单外设： 如逗猫棒或云台，逻辑简单，使用 MicroPython 开发效率最高。
  • 异常自愈闭环： 注意红色的"异常处理"模块，它不仅记录错误，还能指挥 AI 说话（"哎呀，小车断线了，正在重连"），并尝试重启驱动。
